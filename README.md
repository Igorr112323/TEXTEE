# Журнал КубГАУ

Офлайн-учёт посещаемости. Телефон преподавателя — это камера: он сканирует QR-код студента. Для самой отметки сеть, Bluetooth и NFC не нужны.

Вкладка «QR» — «Система автоматизированной переклички». Она не заменяет камеру. Студент сканирует код сети аудитории, затем код сайта на компьютере преподавателя, ставит приложение на iPhone и показывает свой QR. Интернет не нужен.

Стиль окна, цвета, шрифт Manrope и карточки — как в журнале КубГАУ. Отметка идёт картинкой, а не касанием телефонов.

| Файл | Что это |
|---|---|
| `KubGAU-Journal.exe` | Программа на ПК, окно «Журнал КубГАУ» |
| `KubGAU-Teacher.apk` | Android, «КубГАУ Преподаватель» — камера |
| `KubGAU-Student.apk` | Android, «КубГАУ Студент» — показывает QR |
| PWA | То же для iPhone: студент и, если нужно, преподаватель |

Готовые файлы: [релиз v1.0.0](https://github.com/Igorr112323/TEXTEE/releases/tag/v1.0.0).

## Как провести пару

1. На ПК запустите `KubGAU-Journal.exe`. Вкладка «Студенты» → группа → студенты (или импорт из Word). Каждому выдаются логин и пароль.
2. Студент один раз вводит логин и пароль в приложении. Дальше телефон сам показывает QR. Код меняется каждые 5 секунд, скриншот не подходит.
3. На ПК: «Занятия» → группа → **Начать перекличку**. На экране большой код сессии.
4. Преподаватель открывает «КубГАУ Преподаватель» и сканирует код сессии с экрана ПК. Телефон пишет «Группа считана».
5. Студенты по очереди показывают QR. Преподаватель сканирует их камерой. На телефоне сразу имя: «Отмечен» или причина отказа.
6. **Передать на ПК**:
   - показать QR итога в веб-камеру компьютера и на ПК нажать «Считать итог»;
   - или «Сохранить файл» и перенести `KubGAU-rollcall.kjournal` на ПК как обычный файл (кабель, как флешка — это не сеть) → «Импорт файла».
7. **Завершить перекличку**. Занятие попадает в «Журнал», его можно выгрузить в Word.

Клик по строке на ПК по-прежнему ставит или снимает «Есть» вручную.

## Что нельзя обойти

- Аккаунт привязывается к телефону при первой успешной отметке. Чужой телефон не отмечается.
- Если телефон, уже привязанный к одному студенту, показывают за другого, отметка не проходит, а у владельца в списке загорается «⚠ Что-то не так».
- Неверный пароль преподаватель видит сразу: «НЕВЕРНЫЙ ЛОГИН ИЛИ ПАРОЛЬ».
- QR студента живёт около 45 секунд. Старый скриншот камера не примет.

## Вкладка QR

1. На ПК включите точку доступа или подключите компьютер к Wi-Fi аудитории. В Windows адрес точки доступа обычно `192.168.137.1`.
2. Вкладка «QR»: имя сети, пароль (пустой или 8–63 символа), имя преподавателя.
3. На проектор — два кода. Сначала Wi-Fi, потом сайт. Одним кодом телефон это не умеет.
4. На сайте: «Открыть приложение». iPhone: Поделиться → На экран «Домой».
5. Если телефоны не открывают страницу — «Разрешить телефонам». Windows спросит права администратора: это порт и правило брандмауэра.
6. ПИН при запуске по умолчанию `2468`. Сменить можно на той же вкладке.
7. «Копия журнала» пишет файл в папку `backups` рядом с программой. Перед удалением группы копия создаётся сама. Хранятся 20 последних копий и одна в день, 60 дней.

Присутствие по-прежнему отмечает камера. Сайт только ставит приложение и не принимает отметки.

На вкладке «Занятия» перед записью можно нажать «Проверка»: три случайных из уже отмеченных. «Внезапная перекличка» на вкладке QR один раз подаёт сигнал в скрытую минуту — дальше снова камера.

«Журнал» показывает последние 300 занятий. «Сводка» — семестр с 1 сентября или 1 февраля: `+` был, `н` не был, `—` ещё не числился. Таблица сохраняется в CSV. «Экспорт» — карточка занятия в Word.

## iPhone

На iPhone нет APK. В релизе лежит `KubGAU-iPhone-PWA.zip`. Его можно открыть по HTTPS или со вкладки «QR» по адресу компьютера в аудитории. В Safari: Поделиться → На экран «Домой».

Подпись QR студента считается и без HTTPS, поэтому страница аудитории работает. Камера в режиме преподавателя на iPhone по-прежнему просит защищённое соединение — для пары используйте Android-приложение преподавателя.

Внизу экрана есть «Режим преподавателя» — если камерой должен быть iPhone, а не Android.

## Сборка

ПК (Windows, .NET 8):

```bash
dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true -p:SelfContained=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Android (JDK 17, Gradle 8.9):

```bash
cd android && gradle assembleRelease
```

- `android/app/build/outputs/apk/release/app-release.apk` — преподаватель
- `android/student/build/outputs/apk/release/student-release.apk` — студент

PWA — папка `pwa/`. Её можно открыть любым статическим хостингом.
